TAMU Digital Content Accessibility Workflow

Step 1: Essential Material Check

Is this material essential for student understanding or success in the course?

  • ✅ Yes: Proceed to Step 2.
  • ❌ No: Remove or replace with existing accessible material.

Additional questions to consider:

  • Could this content be streamlined or replaced with an already accessible resource?
  • Would students benefit more from a simplified or updated version of this content?
  • Is this content already covered in other course resources?

Step 2: Format Availability Check

Is the content already available in an accessible format elsewhere?

  • ✅ Yes: Link to that resource.
    • TAMU Knowledge Base - Accessibility - Linking to external digital resources
  • ❌ No: Proceed to Step 3.

Step 3: Identify the File Type

  • Word, PowerPoint, or Canvas Page: Proceed to Step 4.
  • PDF: Proceed to Step 5.
  • Video: Proceed to Step 6.
  • Other Formats: Contact Academic Technology.

Step 4: Word Document, PowerPoint, or Canvas Page

  1. Use the built-in Accessibility Checker (Word, PowerPoint, Canvas) to remediate and re-upload.
    • TAMU Knowledge Base - Accessibility - How to use the Microsoft Word accessibility checker
    • TAMU Knowledge Base - Accessibility - How to use the PowerPoint accessibility checker
    • TAMU Knowledge Base - Accessibility - Descriptive hyperlinks
  2. Use Ally/Panorama to help identify further issues that need to be remediated. Remediate and re-upload. Continue until all issues are resolved or contact Academic Technology.
    • Ally Remediation Guide
      • Important: Do not remediate alt text in Ally. Alt text does not carry over in future courses. Use the Canvas page editor or Panorama to add/edit alt text.
    • Panorama Resource Guide

Step 5: PDFs

Do you have the source file (Word or PowerPoint)?

  • ✅ Yes: Update the source file using Step 4 and export as a new PDF.
  • ❌ No: Continue to the check below.

Can you select the text on the page?

  • ✅ Yes: Follow the steps to remediate below.
  • ❌ No: Consider recreating the content in an accessible format (e.g., Canvas page or Word doc) or contact Academic Technology.

Steps to Remediate PDFs:

  1. Use built-in Accessibility Checker (Adobe Acrobat Pro) to remediate and re-upload.
    • TAMU Center for Teaching Excellence PDF Remediation Guide
  2. Use Ally/Panorama to help identify further issues. Remediate and re-upload. Continue until all issues are resolved or contact Academic Technology.
    Note: If the remaining issues are related to tags or table headings, please contact Academic Technology.
    • Ally Remediation Guide
    • Panorama Resource Guide

⚠️ NOTE: Do NOT use the Document Reference tool on PDFs

While Ally shows a score increase when a Document Reference is added, this creates a "false sense of accessibility." The system marks the item as improved, but the underlying PDF remains inaccessible to students using screen readers or other assistive technologies.

Why this matters:

  • Audit Risk: In the event of an accessibility audit, a Document Reference does not satisfy legal requirements. The core document itself must be accessible.
  • Student Experience: Masking the issue doesn't remove the barrier for the student; it simply hides the warning icon for the instructor.

Step 6: Videos

At this time, we are still gathering information from the university regarding expectations for captioning and transcripts for videos. Here is what we know so far:

  • Auto-generated captions are often not sufficient unless reviewed and corrected for accuracy. Most resources like YouTube and Vimeo use auto-generated captions.
  • Use accessibility checkers or browser extensions (like WAVE or Accessibility Insights) to inspect video elements.
  • TAMU Knowledge Base - Accessibility - Transcripts and captions
  • Note on Video Hosting: Mediasite captioning is going away—please replace Mediasite links with Panopto links.
